# TON Pay Shop Bot

Telegram-магазин подписки с оплатой криптой: покупатель платит TON, бот ждёт
подтверждения транзакции в сети и сам выдаёт доступ в закрытый канал.
Подписка продлевается автоматически, есть реферальная программа.

**Стек:** Python 3.11, aiogram 3, SQLite, Tonutils / TonCenter API.

## Что делает

- витрина тарифов: месяц / 3 месяца / год
- счёт на оплату: адрес кошелька + комментарий-идентификатор для сверки
- проверка оплаты по хешу транзакции, автовыдача инвайт-ссылки
- продление подписки с сохранением остатка дней
- реферальная программа: 10% пригласившему, +7 дней приглашённому
- `/admin` — статистика: подписчики, оборот, неоплаченные счета
- журнал всех платежей в SQLite

## Что заменить в бою

1. `check_payment()` — сейчас демо-подтверждение через 20 секунд. В бою:
   запрос транзакций по адресу кошелька (TonCenter / tonutils), сверка
   суммы, комментария счёта и финализации транзакции.
2. `create_invoice()` — сейчас сохраняет счёт в SQLite. В бою сюда же
   добавляется подпись комментария (комментарий-менеджер) либо TON Connect.
3. `grant_subscription()` — сейчас возвращается тестовая ссылка. В бою:
   `bot.invite_link(chat_id=CHANNEL_ID, expire_date=..., member_limit=1)`.
4. `WALLET_ADDRESS` — реальный кошелёк, на который приходит оплата.

## Отличие от первого кейса

Первый кейс (`nft-access-bot`) — доступ по владению NFT-ключом: покупатель уже
имеет ключ, бот только проверяет. Этот — продажа подписки за крипту с
оплатой ончейн, автопродлением и реферальной программой.
